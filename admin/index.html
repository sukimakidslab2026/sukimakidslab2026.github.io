スタンプ設定（お魚が増えていく順番）

スタンプを1個取るごとに、上から順番に、お魚が1種類ずつ川に現れます（どの掲示板のQRコードを読み取ったかには、関係ありません）。 景品をゲットできる条件は 3 個です。最初の 3 個だけでも、川がさびしく見えない順番にしてください。 右の「川の見え方」で、スタンプが1〜6個のときの川の絵を確かめながら、▲▼で並べ替えて、「保存して公開する」を押します。 イベントが始まってから変えると、すでにスタンプを集めている人の絵も、新しい順番に入れ替わります（集めた個数は変わりません）。

    公開の設定（掲示板の地図・開催開始日・開催終了日）

    サイトを公開していても、ここで「公開する」にするまでは、スタンプラリー画面に、掲示板の地図（「掲示板のある場所」）は出ません（初期は非公開です）。 保存すると、参加者の画面には、次に開いたとき（再読み込みしたとき）から反映されます。

    掲示板の地図（スタンプラリー画面の「掲示板のある場所」）

    「公開する」にすると、js/rally-data.js に登録した場所の一覧・地図と、下で入力したGoogleマイマップが、参加者の画面に表示されます。

    マイマップの作り方・リンクのコピーのしかた
    1. Googleマイマップで、掲示板の場所にピンを立てた地図を作ります。
    2. 「共有」で、一般的なアクセスを「リンクを知っている全員が閲覧可」にします（なっていないと、参加者の画面に表示されません）。
    3. 次のどちらかを、上の欄に貼り付けます：地図のURL（https://www.google.com/maps/d/viewer?mid=… や …/edit?mid=…）／「︙」→「自分のサイトに埋め込む」で表示される <iframe …> のタグ。
    4. 地図の最初の位置・拡大（URLの ll=…・z=…）は、URLに入っていれば、そのまま使います。

    プレビュー（参加者の画面では、このように表示されます）

    表示されないときは、マイマップの共有が「リンクを知っている全員が閲覧可」になっているかを確認してください。

    空にすると、開催開始日は、バナーの下に表示されません（スタンプを獲得できるのは、初期値の 2026年12月9日 0:00 からです）。

    この設定を使うには、先に、sql/schema.sql の全体を、SupabaseのSQL Editorで実行してください（実行するまで、変えられません）。

    バナーの下は、開催の期間に合わせて、自動で変わります（開催前：開催開始日／開催中：「開催中！」／終了のあと：「開催は終了しました」）。

    開催の状態（開催前・開催中・終了）と、記録の自動削除

    スタンプのQRコードを読み取ったときに、スタンプをもらえるのは、開催の期間の間だけです（開催開始日の 0:00 〜 開催終了日の 23:59:59。日本時間）。期間の外では、スタンプはもらえず、「開催まで待ってね」「開催終了しました」の画面が出ます（サイトは、そのまま見られます）。 期間の日付は、「公開の設定」で変えられます。

    いまの状態

    手動で切り替え中：あと で、時刻どおりの状態（）に、自動で戻ります。

    手動で切り替える（30分だけ）

    動作確認などのために、スタンプを受け付けるかを、一時的に切り替えられます。切り替えは、30分だけ有効で、30分たつと、何もしなくても、自動で、時刻どおりの状態に戻ります。「自動に戻す」で、すぐに戻すこともできます。 切り替えられるのは、スタンプを受け付けるかだけです（参加者の画面の「開催中！」などの表示は、時刻どおりのままです）。開催前に「開催中にする」で読み取ったスタンプは、開催開始の1秒前の自動削除で、消えます。

    お知らせの画面を確認する（プレビュー）

    スタンプのQRコードを、開催の期間の外で読み取ったときに出る画面を、そのまま確認できます（スタンプは、もらえません。記録も、されません）。

    「開催まで待ってね」の画面を確認（プレビュー） 「開催終了しました」の画面を確認（プレビュー）

    記録の自動削除

    開催が始まる前の記録（動作確認で読み取ったデータなど）は、開催開始の1秒前（初期は 12月8日 23:59:59）に、自動で削除されます。 削除の直前に、削除する記録を、そのまま、データベースの中に保存します（保存できなければ、削除もしません）。保存した記録は、下から、CSVにして手元に保存できます。 削除するのは、開催開始より前にできた記録（読み取り履歴・取得したスタンプ・アンケートの回答・景品の発送先・除外した参加者）だけです。開催が始まってからの記録は、残ります。削除された参加者の端末は、次に開いたとき、はじめての状態（新しい参加者）に戻ります。 自動削除は、1回だけ行われます（あとから、動作確認の記録が増えても、自動では、消えません）。

    記録削除の予定（いま）削除した件数

    念のため、自動削除の前に、いまの記録を、CSVで保存しておくと安心です（個人情報を含みます。取り扱いに注意してください）。

    自動削除のときに保存した記録

    自動削除のときに保存した記録です。「CSVで保存（ZIP）」で、手元に保存できます。保存したあとは、「削除」で、この記録を消してください（景品の発送先などの個人情報を含むため、いつまでも、残さないようにします。元に戻せません）。
